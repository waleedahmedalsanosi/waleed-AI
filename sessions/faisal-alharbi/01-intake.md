## Product

**One-line description:** SaaS platform that enables small and medium Saudi contractors to build, store, and auto-generate professional tender qualification files for government and corporate bids.

**Problem being solved:** Small contractors (5–50 employees) in Saudi Arabia lose government and corporate tender opportunities because their qualification files are incomplete or disorganized. The existing government procurement portal (Etimad) is hard to use and not designed for SME contractors. The entire system runs on paper and personal connections.

**Current solution / status:** Figma prototype complete. No code written. No MVP.

**Key features mentioned:**
- One-time data entry: company profile, certifications, commercial registration, project history
- Auto-generation of qualification files for any specific tender
- Deadline and milestone tracking
- Searchable project history
- Phase 2: AI-based tender recommendations matched to contractor size and specialization

**Technical approach:** SaaS web platform. Phase 2 includes AI/ML for tender matching. Key dependency: API access to government portals (Etimad, Monafasat) — not confirmed available.

## Red Flags / Open Questions

- **Company not incorporated.** Equity grant legally unenforceable until entity exists. Must be resolved before any Dreamy commitment.
- **Government API access unconfirmed.** The auto-generation feature's value depends on integration with Etimad/Monafasat. If these portals don't offer API access, the product reverts to manual data entry — significantly weaker value proposition.
- **No technical co-founder.** Sole founder, no team. Full build dependency on Dreamy.
- **Verbal interest ≠ LOI.** 9/12 contractors said they'd pay "if the solution is right." No signed LOIs, no deposits, no pilot agreements.
- **SAM not validated at price points.** SAR 500–1,500/month is a meaningful expense for a 10-person contracting company. No evidence contractors have bought software at this price before in this category.
- **20% equity offer.** Below Dreamy's typical range — needs negotiation before commitment.
